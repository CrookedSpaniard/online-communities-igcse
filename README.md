# Online Communities — IGCSE ICT

**Live:** https://online-communities-igcse.vercel.app

Interactive lesson for Pearson Edexcel International GCSE ICT, Unit 3 Operating online, Chapter 8 Online communities.

Each section is explained step by step with an interactive mock-up, then followed by a short **✓ Check** activity. The lesson ends with a **Final test** whose results students can copy (or download as .txt) and send to their teacher.

**Sections**

0. Start — what an online community is; function vs features
1. Social networking — profiles and privacy, friend/follow/connect, user suggestions, timeline, groups, tags, targeted marketing, reactions, sharing and going viral, comments, messages, notifications, analytics → ✓ Check
2. Online gaming — multiplayer/MMORPG, profiles, experience points, choosing opponents, guides and forums, statuses, notifications → ✓ Check
3. Online work spaces — cloud storage, editing at the same time, comments, chat rooms, contacts, shared calendars, booking, virtual meetings → ✓ Check
4. Virtual learning environments — single sign-on, wall and notice board, files, auto-marked quizzes, assignments, moderation, gradebooks, access statistics → ✓ Check
5. Wikis and forums — wiki editing and history, threads, sticky notes, ratings, members/moderators/administrators, censoring, block, rules, report → ✓ Check
6. User-generated content and social bookmarking — video/photo sharing, blogs and vlogs (when is a blog a community?), social bookmarking with tags → ✓ Check
7. Global communication — internet users by region, translation tools, Wikipedia in 292 languages → ✓ Check
8. Staying safe online — reporting, anonymity and misrepresentation, never meet alone, disclosure and geotagging, privacy settings, cyberbullying → ✓ Check
9. Key terms (searchable)
10. Final test — 15 multiple-choice + 3 exam-style questions with mark schemes, and **Copy my results**

The copied results include name, class, date, score, time, every section-check score and the written answers. Check scores are kept only in the student's browser tab (sessionStorage); nothing is sent to a server.

**Controls:** Play/Pause (Space), Next (→), Back (←), Restart scene (R), Projector mode (P), Full screen (F). Each scene has its own URL, e.g. `#safety` or `#check-safety`.

Plain HTML, CSS and JavaScript — no build step. All mock-ups are original; names, people and sites are made up.
